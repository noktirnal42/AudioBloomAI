# AudioBloomAI

AudioBloomAI is a macOS audio visualization and processing app built with Swift 6, SwiftPM, Metal, and AudioKit.

## Requirements
- macOS 15+
- Xcode 16+
- Swift 6

## Build (CLI)
- swift build -c release --product AudioBloomApp
- The binary will be at .build/release/AudioBloomApp

## Run
- Grant microphone access when prompted.
